A deterministic one-liner for make.fun's Worst Monday One-Liners bounty: `main.py` writes a single 101-character Monday one-liner to `/output/entry.txt` — "Monday: deploy failed at 9:03, rollback failed at 9:04, and stand-up asked me to circle back to both." No network, no randomness, no clock — every run produces exactly the same bytes.

## Run it

```sh
python3 main.py
```
